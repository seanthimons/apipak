apipak 0.1.0 provides schema-driven R client maintenance through a strict YAML interface, client-owned runtime helpers, fixed offline contracts, and validated file ownership/recovery.

The release includes OpenAPI 3.0/3.1 and Swagger 2 support with explicit unsupported-operation diagnostics, isolated documentation/formatting, maintenance reports and sourceable commands. ComptoxR remains a separate client with declarative policy and explicit chemistry callbacks.
